# PrintStart Adelaide — Part B website

Static HTML/CSS student demonstration site.

## Publish on GitHub Pages
1. Create a public GitHub repository (e.g. `printstart-adelaide`).
2. Upload all HTML files and `style.css` to repository root.
3. Go to Settings → Pages → Deploy from a branch → main / (root) → Save.
4. Wait for the published URL and test navigation on desktop/mobile.

## Enable GA4
1. Create a Google Analytics account/property and web data stream for the published URL.
2. Copy the official Google tag snippet from the web stream into the `<head>` of **every** HTML page (replace the GA4 comment).
3. Update `privacy.html` to accurately describe the live setup and privacy choices; configure consent as required.
4. Open the published site and test Realtime and DebugView (allow time for reporting).
5. Record dated screenshots of the stream configuration and successful tracking.
